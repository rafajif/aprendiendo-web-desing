# HéroesCSS — Aprende CSS

Juego interactivo para aprender CSS resolviendo misiones con superhéroes.
Inspirado en [Flexbox Froggy](https://flexboxfroggy.com).

## Tecnologías

- TypeScript + Vite
- CodeMirror 6 (editor CSS)
- Vitest + fast-check (tests)

## Inicio rápido

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
